# Savings Tracker

A small web app I built to keep track of my savings. I pick a day on the calendar and add what I saved or withdrew, and it works out the weekly, monthly and total amounts for me.

Live: https://Maram0909.github.io/savings-tracker

## What it does

- Calendar by month, with a total for each week
- Add savings or withdrawals on any day, with a note
- Shows saved, withdrawn and net for the month, plus the total of everything
- Sign up and log in, so my data is the same on my phone and my laptop

## Made with

HTML, CSS and JavaScript for the page, and Supabase for the database and login.

## Running it

Make a free Supabase project, create the `transactions` table, then put your URL and key at the top of the script in `index.html`.
